# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины

- **Объём оперативной памяти:** 2048 МБ
- **Количество ядер процессора:** 2
- **Объём диска:** 25 ГБ (динамически расширяемый)
- **Тип и версия ОС:** Linux / Ubuntu Server 24.04 LTS (64-bit)

## 2. Сетевые интерфейсы

- **Адаптер 1 (NAT):** IP `10.0.2.15`. Назначение: выход в Интернет для установки пакетов.
- **Адаптер 2 (Host-only):** IP `192.168.56.103`. Назначение: прямой доступ с хостовой системы (Windows), проброс портов и работа веб-сервера.

## 3. Правило проброса портов

В настройках Адаптера 1 (NAT) создано правило:

- **Имя:** ssh
- **Протокол:** TCP
- **Порт хостовой системы (Windows):** 2222
- **Порт гостевой системы (Ubuntu):** 2222 (изменён со стандартного 22 в рамках hardening).

## 4. Учётные записи

- **student:** входит в группу `sudo`. Использовалась для первоначальной настройки. Аутентификация по паролю.
- **devops:** входит в группу `sudo` и `users`. Основная учётная запись для администрирования. Аутентификация выполняется исключительно по SSH-ключу (`~/.ssh/devops_vm`).

## 5. Служба SSH

- **Порт:** 2222 (сокет-активация `ssh.socket` отключена, используется `ssh.service`).
- **Расположение конфигурации:** `/etc/ssh/sshd_config.d/99-hardening.conf`
- **Изменённые директивы:**
  - `Port 2222`
  - `PermitRootLogin no`
  - `PasswordAuthentication no`
  - `PubkeyAuthentication yes`
  - `MaxAuthTries 3`
  - `AllowUsers devops`
  - `X11Forwarding no`
  - `ClientAliveInterval 300`
  - `ClientAliveCountMax 2`

## 6. Правила межсетевого экрана (UFW)

- **Политики по умолчанию:** `deny incoming`, `allow outgoing`.
- **Разрешённые правила:**
  - `2222/tcp LIMIT` (SSH, ограничение частоты подключений)
  - `80/tcp ALLOW` (HTTP)
  - `443/tcp ALLOW` (HTTPS)

## 7. Снимки состояния

- `01-clean-install` — чистая установка ОС до внесения изменений.
- `02-keys-configured` — настроена ключевая аутентификация для пользователя `devops`.
- `03-ssh-hardened` — применён hardening SSH, UFW настроен и активен, задано локальное доменное имя `devops.local`.

## 8. Веб-сервер

- **Устанавливаемый пакет:** nginx (из официального репозитория Ubuntu).
- **Путь к конфигурации ресурса:** `/etc/nginx/sites-available/devops-site` (активирована через символическую ссылку в `/etc/nginx/sites-enabled/`).
- **Каталог ресурса:** `/var/www/devops-site`, владелец `devops:devops`, права `755` для каталога и `644` для файлов.
- **Пути к сертификату и ключу:**
  - Сертификат: `/etc/ssl/certs/devops.crt` (права `644`, владелец `root`).
  - Закрытый ключ: `/etc/ssl/private/devops.key` (права `600`, владелец `root`).
- **Команда формирования сертификата:**
  ```bash```
  sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
    -keyout /etc/ssl/private/devops.key \
    -out /etc/ssl/certs/devops.crt \
    -subj "/CN=devops.local" \
    -addext "subjectAltName=DNS:devops.local"

## 9. Контейнеризация

- **Способ установки Docker Engine и его версия:** Официальный репозиторий Docker, установлен пакет `docker-ce` (версия 29.9.2).
- **Участники группы docker:** Пользователь `devops` добавлен в группу `docker`.
- **Расположение проекта на сервере:** `~/app`
- **Расположение файла `.env` и его права:** `~/app/.env`, права `600`.
- **Публикуемые порты и адреса:** `127.0.0.1:5000` (порт приложения, доступен только локально); порт СУБД 5432 не публикуется.
- **Именованные тома:** `app_db_data` (для хранения данных PostgreSQL).
- **Конфигурация обратного прокси-сервера:** в Nginx добавлен блок `location /app/`, который проксирует запросы на `http://127.0.0.1:5000/`.
