# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины
- Объём оперативной памяти: 2048 МБ
- Количество ядер процессора: 2
- Объём дискового накопителя: 25 ГБ (динамически расширяемый)

## 2. Сетевые интерфейсы
- Адаптер 1 (NAT): IP-адрес 10.0.2.15. Назначение: доступ в Интернет, проброс портов.
- Адаптер 2 (Host-only): IP-адрес 192.168.56.103. Назначение: прямой доступ с хостовой системы (Windows).

## 3. Правило проброса портов
- Порт хостовой системы (Windows): 2222
- Порт гостевой системы (Ubuntu): 2222

## 4. Учётные записи
- `student`: входит в группу sudo. Аутентификация по паролю (используется для первичной настройки).
- `devops`: входит в группу sudo. Аутентификация по ключу `~/.ssh/devops_vm`.

## 5. Служба SSH
- Порт: 2222
- Расположение файла конфигурации: `/etc/ssh/sshd_config.d/99-hardening.conf`
- Изменённые директивы и их значения:
  - `Port 2222`
  - `PermitRootLogin no`
  - `PasswordAuthentication no`
  - `PubkeyAuthentication yes`
  - `MaxAuthTries 3`
  - `AllowUsers devops`

## 6. Правила межсетевого экрана
- Политика по умолчанию для входящих: `deny`
- Политика по умолчанию для исходящих: `allow`
- Перечень правил:
  - `2222/tcp LIMIT IN` (SSH с ограничением частоты подключений)
  - `80/tcp ALLOW IN` (HTTP)
  - `443/tcp ALLOW IN` (HTTPS)

## 7. Снимки состояния
- `01-clean-install`: создан после установки ОС и обновления системы.
- `02-keys-configured`: создан после настройки ключевой аутентификации и файла `~/.ssh/config`.
- `03-ssh-hardened`: создан после усиления защиты SSH и настройки UFW.
